# Gym Tracker Pro ⚡️

Ứng dụng Web (PWA) theo dõi lịch tập Gym, quản lý nhóm cơ, theo dõi tiến trình và chỉ số cơ thể với giao diện Dark Theme (Bold + Typography) cực kỳ mạnh mẽ.

## Tính Năng Chính
- **Lịch Tập Tuần (Schedule):** Lên kế hoạch tập luyện chi tiết cho 7 ngày trong tuần, tự do chọn lựa nhóm cơ chính, nhóm cơ bổ trợ và set/rep phù hợp.
- **Tập Luyện Hôm Nay (Today):** Dashboard tổng hợp danh sách bài tập trong ngày. Khả năng đánh dấu các set hoàn thành và tích hợp **Mini-widget Rest Timer** đếm ngược thời gian nghỉ giữa hiệp.
- **Tiến Độ (Progress):** Ghi chép chỉ số cơ thể hàng ngày (Cân nặng, Tỉ lệ mỡ / Body Fat) và hiển thị qua biểu đồ trực quan giúp theo dõi sự thay đổi.
- **Từ Điển Bài Tập (Exercises):** Khám phá, tìm kiếm và lọc danh sách các bài tập dựa trên nhóm cơ và thiết bị.
- **Hồ Sơ (Profile):** Hệ thống thống kê chuỗi ngày tập luyện liên tiếp (Streak), tổng số buổi tập, và "bản đồ nhiệt" (Activity Map) hoạt động trong 14 ngày qua.

## Tech Stack
- **Core Frontend:** React 19 + Vite + TypeScript
- **Styling:** Tailwind CSS v4 
- **Đồ thị (Charts):** Recharts
- **Icons:** Lucide React
- **Tiện ích thời gian:** date-fns

## Cài đặt trên điện thoại
Ứng dụng đã được tối ưu hiển thị di động và cấu hình sẵn meta-tags để hoạt động như một **Progressive Web App (PWA)** không viền:
1. Mở link ứng dụng trên trình duyệt điện thoại (Safari trên iOS hoặc Chrome trên Android).
2. Chọn tuỳ chọn **"Add to Home Screen" (Thêm vào Màn hình chính)**.
3. Mở ứng dụng từ màn hình khởi động như một app hoàn chỉnh không cần build APK.
